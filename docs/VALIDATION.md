# Перевірка MVP

Дата: 7 вересня 2026. Windows, Node.js 24.20.0, Next.js 16.3.4, Chrome headless.

- `npm run typecheck` — успішно.
- `npm run lint` — успішно, без попереджень.
- `npm test` — 16 успішних тестів SQL/RLS/валідації/CSV/Telegram.
- `npm run test:e2e` — 3 успішних браузерних тести (останній повний прогін: 39,2 с).
- `npm run build` — успішна production-збірка.

Браузером перевірено вхід, створення напрямку/курсу/набору, відкриття публічної форми в іншій сесії, надсилання заявки, її пошук, зміну статусу, примітку, створення групи, додавання дитини, створення учня, склад групи, архівування та відновлення. Окремо перевірено закриту форму, обов’язкові поля та відсутність горизонтального переповнення на ширині 390 px.

SQL-тести застосовують міграцію до PGlite та реально перемикають ролі PostgreSQL. Перевірено відсутність анонімного читання заявок, доступ без staff-профілю, ідемпотентність реєстрації, серверну валідацію, історію статусів, примітки, конвертацію lead → student, членство в групі, FK і несумісні групи.

Візуальний перегляд: [головна CRM](previews/dashboard.png), [мобільна реєстрація](previews/registration-mobile.png).

Telegram: браузером пройдено створення групи через демо-адаптер, вибір адресата, обов’язковий preview, публікацію, історію message ID, закріплення, видалення з підтвердженням, планування й скасування. Перевірено відмову cron/webhook без секретів та успішний авторизований виклик cron. SQL-тести додатково перевіряють блокування подвійного отримання доставки, гонку скасування, атомарне збереження аудиторії, архівованих адресатів, приватність credentials; тести контенту — очищення HTML, шифрування, DST і ліміти альбомів.

Додатково перевірено реальний Bot API `getMe`. Реальні відправлення, MTProto, віддалений Storage та webhook Telegram ще не перевірялися. Налаштування та контрольний сценарій після підключення — у [TELEGRAM.md](TELEGRAM.md).

Після локальних тестів обидві міграції застосовано до порожнього робочого Supabase-проєкту. Створено адміністратора, перевірено реальний Auth, staff-доступ до таблиць і заборону читання Telegram credentials. Production-збірку запущено локально; браузером перевірено вхід і відкриття Telegram. Віддалене розгортання на сервері користувача ще не перевірялося.
