# Розробка та перевірка змін

Використовуйте Node.js 24 та `npm ci`. Для локальної роботи без зовнішніх сервісів доступний `npm run demo`; цей адаптер вимкнений у production.

Перед pull request виконайте `npm run lint`, `npm test` та `npm run build`. Браузерні сценарії: `npm run test:e2e` (потрібен Chrome і вільний порт 3000). Не запускайте демо одночасно з E2E.

Створюйте окрему гілку для зміни. У коміті пояснюйте результат, а в pull request — проблему, зміну поведінки й виконані перевірки. Коментарі в коді мають пояснювати причину рішення, особливо блокування черги, перевірки доступу й обробку часткової доставки.

Не змінюйте вже застосовані SQL-міграції: додавайте новий файл із наступним номером. Не включайте секрети, реальні контакти дітей, локальні бази або production-скриншоти. Приклади даних мають бути вигаданими.
